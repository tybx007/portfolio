02 / COMPUTER GRAPHICS CSE 428 Lab · Nov 2026

GARGANTUA — Ultimate Black Hole Explorer

An interactive real-time 3D black hole visualisation built with C++, OpenGL and GLSL fragment shaders.

  • Rendered an event horizon, approximate gravitational lensing, photon-ring glow and a procedural accretion disk on the GPU.
  • Used ray reconstruction, noise-driven plasma patterns, Doppler-inspired brightness and a procedural starfield.
  • Reached ~30 FPS at 1280×720 on Intel Iris Xe; 8 of 8 functional tests passed.
