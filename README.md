# CV / Portfolio files

Three separate deliverables:

1. **`immersive-portfolio.html`** — igloo.inc-inspired, scroll-driven portfolio.
   - Dark "void" canvas with a rotating crystal wireframe, particle field, chromatic text glitches and scramble effects.
   - Scroll reveals, tilting "ice block" project cards, and links that morph the particle formation on hover.
   - Uses your portrait photo and includes all three projects.
2. **`portfolio-cv.html`** — interactive visual CV with two switchable themes: **Bento** (light card grid) and **Terminal** (dark developer). Includes your photo, copy-email button and concise project cards without expandable breakdowns. The choice is remembered in the browser.
3. **`resume.html`** + **`resume.pdf`** — ATS-friendly, single-column, one-page resume using the CV text you supplied, including the BUET CTF 2023 achievement and References line. Standard font, no graphics/tables, plain visible URLs.

## Projects included

- JKKNIU Admission Management System — PHP/MySQL, 5 role portals, 13/13 tests passed.
- GARGANTUA — C++/OpenGL/GLSL black hole visualisation, ~30 FPS at 720p, 8/8 tests passed.
- University Result Management System (uniRMS) — PHP/MySQL role-based result processing, GPA/CGPA calculation and PDF transcripts with verification codes.

Source reports are kept in this folder and linked from both HTML portfolios.
